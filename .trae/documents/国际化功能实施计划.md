# Vibe-Trading 国际化（i18n）功能实施计划

## 目标
为 Vibe-Trading 前端添加多语言支持，实现中文简体（zh-CN）、中文繁体（zh-TW）和英文（en）三种语言的切换功能。

## 现状分析
- ✅ 已有的基础 i18n 系统（React Context 实现）
- ✅ 32 个组件已使用 `useI18n()` hook
- ✅ 所有翻译字符串集中在 `frontend/src/lib/i18n.tsx` 的 `messages` 对象中
- ❌ 当前仅支持英文
- ❌ 缺少语言切换器 UI
- ❌ 缺少语言持久化机制

## 实施步骤

### 步骤 1：重构 i18n 基础架构
**文件**: `frontend/src/lib/i18n.tsx`

1. **创建语言类型定义**
   - 定义 `Language` 类型: `'en' | 'zh-CN' | 'zh-TW'`
   - 创建 `languages` 配置对象，包含语言名称和标识

2. **重构 messages 结构**
   - 将当前的单个 `messages` 对象改为嵌套结构
   ```typescript
   const messages = {
     en: { /* 英文消息 */ },
     'zh-CN': { /* 简体中文消息 */ },
     'zh-TW': { /* 繁体中文消息 */ }
   }
   ```

3. **扩展 I18nProvider**
   - 添加语言状态管理（使用 localStorage 持久化）
   - 添加 `setLanguage(lang: Language)` 方法
   - 添加 `currentLanguage` 状态
   - 提供 `t()` 函数根据当前语言返回对应翻译

4. **创建类型安全接口**
   ```typescript
   type Messages = typeof messages['en'];
   type I18nContextType = {
     t: Messages;
     language: Language;
     setLanguage: (lang: Language) => void;
     languages: { code: Language; name: string; nativeName: string }[];
   }
   ```

### 步骤 2：创建语言选择器组件
**新文件**: `frontend/src/components/common/LanguageSelector.tsx`

1. **功能需求**
   - 下拉选择器显示三种语言
   - 显示语言原生名称（如 "English", "简体中文", "繁體中文"）
   - 选中当前语言高亮显示
   - 切换时自动更新所有翻译
   - 保持响应式设计

2. **UI 设计**
   - 使用 Lucide 图标（Globe/Languages）
   - 位置：设置页面或顶部导航栏
   - 样式与现有 UI 保持一致

3. **实现要点**
   - 使用 `useI18n` 获取语言状态和切换函数
   - 点击外部关闭下拉菜单
   - 键盘可访问性（Tab 导航、Enter 选择）

## 技术要点

### 翻译键命名规范
```
category_subsection_key
- home_welcome_title
- settings_llm_provider
- metrics_total_return
- chart_overlay_ma
```

### 特殊文本处理
- **变量插值**: 保持 `{variable}` 格式
- **HTML 标签**: 使用 React 组件替代
- **复数形式**: 暂不处理（当前无复数需求）
- **日期/数字格式**: 使用 `Intl` API 或现有 `formatters.ts`

### 性能优化
- 消息对象使用 `const assertions` 保证类型安全
- Context 使用 `memo` 避免不必要的重渲染
- 语言切换仅更新 Context，不触发完整应用重载

## 风险与注意事项

### 风险
1. **翻译完整性**: 166+ 条消息需要准确翻译
2. **术语一致性**: 金融术语在三种语言间保持一致
3. **向后兼容**: 确保现有英文用户无感知变化

### 注意事项
1. 不修改任何业务逻辑，仅添加翻译层
2. 保持现有 UI 布局不变
3. 确保 TypeScript 类型安全
4. 遵循 React 19 最佳实践
